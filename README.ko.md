# 피카츄 배구 2대2

[English](README.md) | 한국어

[gorisanson/pikachu-volleyball](https://github.com/gorisanson/pikachu-volleyball)에 로컬 4인 2대2 모드를 추가한 포크입니다. 기존 게임의 이동 및 충돌 동작은 유지합니다.

배포 후 GitHub Pages 주소: [한국어](https://ilesejin.github.io/pikachu-volleyball-2v2/ko/) · [English](https://ilesejin.github.io/pikachu-volleyball-2v2/en/).

## 게임 모드

한국어와 영어 페이지는 기본적으로 2대2 모드로 시작합니다. 애니메이션 메뉴에서 점프/아래 키로 항목을 고르고 공격 키로 확정합니다. 방향키를 한 번 누를 때 한 항목씩 이동하며, 메뉴 시작 애니메이션 중 공격 키를 누르면 선택 화면으로 넘어갑니다.

| 모드                   | 왼쪽 팀                              | 오른쪽 팀               |
| ---------------------- | ------------------------------------ | ----------------------- |
| 사람 1명 + 컴퓨터 3명  | 확정할 때 누른 키로 조작할 선수 선택 | 나머지 세 자리는 컴퓨터 |
| 사람 2명 + 컴퓨터 2명 | Z: 사람, Enter: 컴퓨터 | Z: 컴퓨터, Enter: 사람 |
| 사람 4명   | P1 + P2: 사람                        | P3 + P4: 사람           |

**사람 1명 + 컴퓨터 3명**에서는 **Z → P1**, **V → P2**, **쉼표 → P3**, **Enter → P4**로 조작할 선수를 선택합니다. P1/P2는 왼쪽 팀, P3/P4는 오른쪽 팀입니다. 시작 위치는 왼쪽부터 **P1–P2–P3–P4** 순서입니다. 오른쪽 팀은 P4부터 서브하며 교대 방식에서는 다음에 P3가 서브합니다.

같은 팀 선수는 서로 겹치거나 통과할 수 있습니다. 컴퓨터 선수는 앞쪽/뒤쪽 구역을 나누어 담당합니다. 애니메이션 메뉴 배경은 설정한 코트 너비 전체를 채웁니다.

**게임 → 기존 1대1** 또는 **게임 → 2대2**에서 경기 형식을 바꿀 수 있습니다. 기존 1대1은 사람 vs 컴퓨터와 사람 vs 사람을 지원합니다. 영어, 한국어, 중국어 번체 페이지 모두 같은 2대2 모드와 설정을 지원합니다. 메뉴에서 입력 없이 기다리면 시간 제한 없는 컴퓨터 시범 경기가 시작됩니다.

2대2 AI는 앞/뒤 구역을 나누어 수비하며 실제 네트 물리 규칙으로 공격 궤적을 확인합니다. 상대 두 명의 위치를 고려하고, 수평·하향 스매시가 실패할 상황에서는 위로 공을 올립니다. 기존 1대1 AI와 이동·충돌 규칙은 그대로 유지됩니다.

## 조작법

모든 사람 선수는 하나의 물리 키보드를 함께 사용합니다. 선수마다 색상이 다릅니다.

| 선수 | 점프 | 왼쪽 | 아래+오른쪽 | 오른쪽       | 아래           | 공격 / 확정 |
| ---- | ---- | ---- | ----------- | ------------ | -------------- | ----------- |
| P1   | W    | A    | S           | D            | X              | Z           |
| P2   | Y    | G    | H           | J            | B              | V           |
| P3   | P    | L    | —           | 따옴표 (`'`) | 세미콜론 (`;`) | 쉼표 (`,`)  |
| P4   | ↑    | ←    | —           | →            | ↓              | Enter       |

P3의 문장부호 키는 **Shift 없이 해당 위치의 키**를 누릅니다. 키보드에 `"`, `:`, `<`로 표시되어 있어도 동일합니다. 점프, 다이빙, 강타 동작은 기존 게임을 따릅니다. 점프 중 공격 키를 누르면 강타하고, 서 있는 상태에서 이동 방향과 공격 키를 함께 누르면 다이빙합니다.

기존 1대1에서 왼쪽 선수는 D/G로 이동, R로 점프, V로 아래, F로 아래+오른쪽, Z로 공격합니다. 오른쪽 선수는 방향키와 Enter를 사용합니다. 컴퓨터 대전에서 Z로 확정하면 왼쪽, Enter로 확정하면 오른쪽을 조작합니다.

메뉴 순서는 **사람 1명 → 사람 2명 → 사람 4명**입니다. 선택한 게임 속도는 모드 변경, 경기 재시작, 사이트를 다시 열어도 유지됩니다.

**Esc**로 메뉴 바를 표시하거나 숨길 수 있습니다. 일시정지, 속도, 소리, 승리 점수, 연습 모드는 페이지 메뉴에서 설정합니다. 게임 소개 패널에서도 2대2 조작법을 볼 수 있습니다.

## 코트 및 서브 설정

기본 너비는 **한쪽 코트당 340**, **전체 680**입니다. **설정 → 2대2 한쪽 코트 너비**에서 216 이상의 정수를 입력한 뒤 적용 버튼 또는 Enter를 누릅니다.

**설정 → 2대2 서브…**에서 다음 옵션을 선택할 수 있습니다.

| 옵션                                          | 선수 시작 위치                                          | 공 시작 위치                      |
| --------------------------------------------- | ------------------------------------------------------- | --------------------------------- |
| 1. 공은 뒤쪽 고정 · 선수 자리 교대            | 팀이 서브할 때마다 두 선수의 뒤쪽/중앙 자리가 바뀝니다. | 항상 뒤쪽입니다.                  |
| 2. 선수 자리 고정 · 공 위치 교대 **(기본값)** | P1/P4는 뒤쪽, P2/P3는 자기 코트 중앙에서 시작합니다.    | 두 선수 사이를 번갈아 이동합니다. |
| 3. 선수와 공 위치 모두 고정                   | 옵션 2와 같은 고정 위치이며 P1/P4가 항상 서브합니다.    | 항상 뒤쪽입니다.                  |

공은 서브 선수보다 네트 쪽으로 20만큼 떨어진 위치에서 시작합니다. 팀마다 서브 순서를 따로 기록하며, 컴퓨터의 앞쪽/뒤쪽 담당 구역은 선수 시작 위치를 따릅니다.

다른 너비나 서브 옵션을 적용하면 같은 사람/컴퓨터 구성으로 2대2 경기가 0–0부터 다시 시작됩니다. 설정은 현재 페이지 세션 동안 유지되며 경기 형식을 바꿔도 기억합니다. 기존 1대1에서 변경하면 다음 2대2 경기에 적용되며 1대1 경기는 바뀌지 않습니다.

초기 기본값은 [doubles_config.js](src/resources/js/doubles_config.js)에서 바꾼 뒤 다시 빌드할 수 있습니다.

## 로컬 실행

테스트에는 Node.js 18 이상이 필요합니다. Node.js 22.11.0에서 검증했습니다. npm 8 이상을 권장하며, 필요한 Pixi peer 패키지를 명시적으로 추가한 뒤 npm 6에서도 새로 설치하여 검증했습니다.

```sh
git clone https://github.com/ilesejin/pikachu-volleyball-2v2.git
cd pikachu-volleyball-2v2
npm ci
npm start
```

webpack이 출력한 주소를 브라우저에서 열고 `/ko/` 또는 `/en/`으로 접속합니다.

| 명령어           | 기능                                                         |
| ---------------- | ------------------------------------------------------------ |
| `npm start`      | 개발 서버를 시작합니다.                                      |
| `npm run build`  | `dist/`에 배포용 게임을 생성합니다.                          |
| `npm test`       | 기존 물리 보존 검사를 포함한 23개 회귀 테스트를 실행합니다.  |
| `npm run deploy` | 빌드 후 `dist/`를 `origin`의 `gh-pages` 브랜치에 게시합니다. |

배포용 빌드를 로컬에서 확인하려면 다음 명령을 실행합니다.

```sh
npm run build
npx http-server dist
```

## GitHub Pages 배포

현재 배포 스크립트는 `gh-pages -d dist`입니다. `predeploy`가 먼저 `npm run build`를 자동 실행합니다. 업로드 대상은 `origin` Git 원격 저장소이므로 배포 전에 확인합니다.

```sh
git remote get-url --push origin
```

이 포크의 대상은 `https://github.com/ilesejin/pikachu-volleyball-2v2.git`입니다. 해당 저장소에 쓰기 권한이 있는 Git 계정으로 배포합니다.

```sh
npm run deploy
```

GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**, **gh-pages** 브랜치, **/ (root)** 폴더를 선택하고 Save를 누릅니다. GitHub의 게시가 완료되면 [ilesejin.github.io/pikachu-volleyball-2v2/](https://ilesejin.github.io/pikachu-volleyball-2v2/)에서 접속할 수 있습니다. 루트 주소는 `/en/`으로 이동하며 한국어는 `/ko/`에 있습니다.

이 명령은 빌드된 웹사이트를 게시합니다. 소스 변경 사항은 저장소의 개발 브랜치에서 별도로 관리합니다.

## 패키지 설치 문제 해결

webpack에서 `@pixi/utils`, `@pixi/math`, `@pixi/runner`, `@pixi/graphics`, `@pixi/text`를 찾지 못한다면 최신 변경 사항을 받은 뒤 `npm ci`를 다시 실행하세요. 이 패키지들은 현재 **6.4.2**로 고정한 명시적 의존성이므로 npm 6에서도 설치됩니다. `package-lock.json`도 함께 유지하세요.

번들 크기 권장 사항과 오래된 Browserslist 데이터베이스 알림은 모듈 누락 오류와 별개입니다. Workbox precache 한도는 8 MiB로 설정되어 있어 큰 개발용 vendor 번들도 포함합니다.

## 제작 및 원본 출처

1997년 원본 윈도우 게임은 **SACHI SOFT / SAWAYAKAN Programmers**와 **Satoshi Takenouchi**가 제작했습니다. **이규태(Kyutae Lee, gorisanson)**가 핵심 물리 엔진과 AI를 리버스 엔지니어링하여 원본 JavaScript 버전을 구현했습니다. 이 포크는 위에 설명한 로컬 2대2 기능을 추가합니다.

원본 리버스 엔지니어링에는 [Ghidra](https://ghidra-sre.org/), [Cheat Engine](https://www.cheatengine.org/), [OllyDbg](http://www.ollydbg.de/), [Resource Hacker](http://www.angusj.com/resourcehacker/)가 사용되었습니다. 렌더링은 [PixiJS](https://github.com/pixijs/pixijs)를 사용합니다.

## 1명/2명 모드의 기본 조작과 F/V 설정

사람 2명 + 컴퓨터 2명에서는 Z로 왼쪽 팀(P1+P2), Enter로 오른쪽 팀(P3+P4)을 고릅니다. 첫 번째 선수는 RDFGVZ, 두 번째 선수는 방향키/Enter를 사용합니다. 두 사람은 항상 같은 팀입니다. 사람 1명 + 컴퓨터 3명에서는 Z/V/쉼표/Enter로 P1/P2/P3/P4를 고르고 RDFGVZ와 방향키/Enter를 모두 사용할 수 있습니다. 기존 선수별 W/A/S/D/X/Z 등의 키 표는 사람 4명 모드에 적용됩니다.

R은 점프, D/G는 좌우 이동, Z는 공격입니다. 기본 F는 아래+네트 쪽(왼쪽 코트에서 아래+오른쪽, 오른쪽 코트에서 아래+왼쪽), V는 아래입니다. **설정 → 2대2 RDFGVZ F/V 설정**에서 **F: 아래 / V: 사용 안 함**으로 바꿀 수 있고, 사이트를 다시 열어도 이 브라우저에 저장됩니다. 1대1 조작에는 영향을 주지 않습니다. 메뉴에서 V로 P2를 선택하는 기능은 계속 사용할 수 있습니다.

자동 브라우저 테스트는 항상 Chrome 소리를 음소거한 상태로 실행합니다.
